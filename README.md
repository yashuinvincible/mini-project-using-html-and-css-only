# Side Navigation Bar Project

A responsive and interactive sidebar navigation menu created using pure **HTML5** and **CSS3**.

## ✨ Features
- **Modern UI Design:** Clean layout featuring a camera background image.
- **Interactive Navigation:** Smooth CSS `:hover` effects on navigation links.
- **CSS Animations & Transforms:** Modern look with CSS transform properties and smooth transitions.
- **Pure CSS:** No external JavaScript used for the styling and interactions.

## 🛠️ Tech Stack
- **HTML5:** Semantic markup and structure.
- **CSS3:** Flexbox/Layout, CSS Transitions, Transforms, and Hover effects.
